---
name: Page header consistency
description: User's visual consistency requirement for content and administration pages.
---

Use Logs, Tasks, and Projects as the visual reference for page headers and descriptions, including administration pages.

**Why:** The user requested that Knowledge, Policies, Procedures, and administration pages match the other pages' header text, font, size, and color rather than use separate heading styles.

**How to apply:** When adding or changing a top-level page header, preserve the same title and description typography as the reference pages. Do not introduce larger or accent-colored page headings for administration.
