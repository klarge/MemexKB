---
name: Media cleanup safety
description: Product expectations and safety rules for deciding whether an uploaded image can be removed.
---

Media cleanup is an administrator-reviewed action, not automatic deletion when a photo disappears from an article. Protect references in retained history, reusable content, and other saved surfaces. An image's article association alone does not establish actual usage.

**Why:** The user selected a media list with safe cleanup after being told that deleting images absent from the latest article could break historical viewing and restoration. Prefer retaining extra media over damaging recoverable content.

**How to apply:** Show a preview and obtain explicit confirmation, then recheck only that preview's candidates atomically with deletion. New rich-content surfaces must be added to both reference discovery and its concurrent-write barrier. Treat editable diagram PNGs as containers of potentially compressed references, not just flattened pictures. Recent uploads need a grace period because the server cannot see unsaved local drafts; deletion warnings must explain that older unsaved drafts are outside this protection.
